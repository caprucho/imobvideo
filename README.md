# ImobVideo — S6 Imóveis

Skill pessoal para editar vídeos imobiliários no padrão S6 Imóveis. Inclui a logo oficial, fontes, referências e o fluxo de revisão, publicação no YouTube e vínculo no Tecimob.

## Instalar em outro computador

No Codex instalado no outro computador, envie:

```text
Use $skill-installer para instalar a skill ImobVideo deste repositório:
https://github.com/caprucho/imobvideo/tree/main/skills/imobvideo
Inclua todos os recursos e valide a instalação.
```

Este repositório é público: a skill pode ser consultada e instalada pelo link, sem convite de acesso ao repositório. Não compartilhe senhas ou tokens no chat.

## Usar

Peça “Use $imobvideo” e forneça o vídeo, a música com os créditos aplicáveis e o link do anúncio. A skill pede as informações que faltarem.

O vídeo é finalizado e mostrado antes de qualquer envio externo. Após o OK da edição, é necessária confirmação para publicar no canal YouTube S6 Imóveis e para inserir o link no campo próprio do anúncio no Tecimob.

A logo, contato e identidade visual são da S6 Imóveis. Cada computador precisa de seus próprios acessos autorizados ao YouTube e ao Tecimob. A skill não fornece acesso a essas contas e não inclui música licenciada.
